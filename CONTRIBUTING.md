# Contributing

Preserve local processing, input bounds, finite metric validation, and cancellation of the underlying Music Understanding session. Keep AVAudioPlayer and observable UI state on the main actor. Do not fabricate analysis when the framework returns no result.

Run core tests, both platform builds, and the native workflow for relevant changes. Distinguish synthetic-fixture checks from representative music validation. Include only original or appropriately licensed audio fixtures, never private recordings, signing profiles, or credentials.
